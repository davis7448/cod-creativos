# ads-invest

Skill del plugin **cod-creativos**. La guía de instalación y uso está en el [README principal](../../README.md).

Contenido de esta carpeta:
```
ads-invest/
├── SKILL.md                         ← reglas de la investigación y de los creativos
├── references/
│   ├── tecnico-busqueda.md          ← cómo buscar y descargar (Drive, AliExpress, TikTok, Meta)
│   ├── produccion-creativos.md      ← guion, voz, música, material, stock, QA
│   ├── voces-omnivoice.md           ← instalación y uso de OmniVoice + whisper
│   ├── montaje-ffmpeg.md            ← función build de ffmpeg y subida a Meta por API
│   └── entrega-artifact.md          ← las 21 secciones de la investigación creativa completa
├── scripts/
│   ├── gen_music.py                 ← música de fondo original (sin derechos de terceros)
│   └── download_swipe_media.py      ← descarga masiva desde swipe_file.json (opcional)
├── extension/                       ← extensión de Chrome para exportar swipe_file.json (opcional)
└── templates/                       ← REGISTRO-INVESTIGACION, BANCO-ANGULOS, COPY, RANKING
```
